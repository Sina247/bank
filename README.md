# 🏦 Hoo Bank

**Hoo Bank** is a modern, responsive **single-page application (SPA)** built with **React**, **JavaScript**, **Tailwind CSS** and **Vite**. It provides a sleek, user-friendly banking interface where users can manage accounts, view transaction history and experience real-time UI updates all in a fully responsive and frontend-only environment.

---

## 🚀 Features

- 💳 **Account Management** : View and organize bank accounts.
- 📜 **Transaction History** : Track all transactions with clear and static records.
- ⏱️ **Real-Time UI Updates** : Dynamic updates for balances and transactions (frontend-only).
- 📱 **Responsive Design** : Mobile-first layouts that adapt seamlessly to desktop screens.
- ⚡ **High Performance SPA** : Powered by React and Vite for fast loading and smooth interactions.
- 🌐 **Modern UI** : Clean, intuitive design optimized for usability and accessibility.
